# Job Radar Georgia

Личный монитор вакансий для кандидата из Грузии. Закрытый репозиторий, сайт не опубликован, Pages не включён.

## Данные
19 вакансий, 13 платформ, 6 исключённых площадок. Исходные ячейки Excel и ссылки сохранены в dist/data/original-*.json. Ручная дата таблицы 21.11.2026 отделена от автоматических проверок. Неизвестный формат не считается удалённым. 5CA исключена, Bolt разрешён.

Интерфейс читает data/bundle.json с cache:no-store. data.js — резервный снимок с предупреждением при ошибке загрузки. JSON и интерфейс предполагается публиковать на одном домене, без токенов в браузере. Избранное и прогресс хранятся в localStorage, отдельно от базы, без синхронизации устройств.

## Интеграции и ограничения
- Wolt: официальный список в Грузии и JobPosting на страницах вакансий.
- Welo Data: публичный Lever API. Приглашения в базу кандидатов (talent_pool) отделены от оплачиваемых вакансий.

Остальные источники требуют ручной проверки. Регистрация на платформе не подтверждает работу или выплаты. География не гарантирует соответствие языковым требованиям. Выплаты, KYC и ставки из Excel остаются неподтверждёнными.

Ошибка источника не обновляет last_verified_at и не закрывает запись. Закрытие требует минимум двух подтверждений отсутствия с интервалом 12 часов. Подтверждение в интерфейсе устаревает через 48 часов. История — check-history.json; исходные записи не удаляются.

## Автоматизация
.github/workflows/radar.yml содержит ручной запуск и ежедневное расписание 0 6 * * * UTC — примерно 10:00 Asia/Tbilisi. Возможны задержки GitHub. scheduled_run_confirmed устанавливается только после события schedule; ручной тест не подтверждает плановый запуск.

Workflow тестирует правила, опрашивает источники, собирает снимок и сохраняет данные в git. Сайт не публикует. last_run_at — попытка запуска, last_database_update — сохранение базы, last_checked_at — попытка проверки записи, last_verified_at — подтверждение. Сохранение ошибок не подтверждает вакансии.

## Настройка
Изменять dist/data/search-config.json: ключевые слова, disabled_categories, исключённых работодателей и языки заголовков, форматы, занятость, приоритеты, geographic_terms. Расширение стран требует также изменения географических терминов и параметров источников: Wolt сейчас ограничен Грузией. Новый сайт обычно требует отдельного адаптера scripts/radar.py и записи sources.json. Исключённые платформы автоматически не возвращаются.

## Разработка
Python 3.12, мониторинг использует стандартную библиотеку.

```sh
python -m unittest discover -s tests -v
python scripts/radar.py
python scripts/build.py
```

scripts/import_data.py — только первоначальный импорт: повторный запуск перезапишет рабочие результаты. Не включать в ежедневный workflow.

Тесты покрывают ошибки, закрытие, повторное открытие, дедупликацию, географию, исключения, влияние конфигурации, даты, обнаружение новых записей и talent_pool. Синтетические находки не являются реальными вакансиями. dist/qa.html проверяет семь ширин; Chromium не заменяет реальное устройство Safari/iPhone.

## Публикация
Только после отдельного согласия владельца. Бесплатный Pages может потребовать публичного репозитория; изменение видимости также согласовывается. До этого не включать Pages или публичный preview. После публикации отдельно проверить обновление JSON и кэш. Платные API и подписки не используются.
