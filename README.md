# Job Radar Georgia

Личный монитор вакансий для кандидата из Грузии. Публикация на GitHub Pages разрешена владельцем 21.11.2026. Репозиторий публичный.

## Данные
19 вакансий, 13 платформ, 6 исключённых площадок. Исходные ячейки Excel и ссылки сохранены в dist/data/original-*.json. Ручная дата таблицы 21.11.2026 отделена от автоматических проверок. Неизвестный формат не считается удалённым. 5CA исключена, Bolt разрешён.

Интерфейс читает data/bundle.json с cache:no-store. data.js — резервный снимок с предупреждением при ошибке загрузки. JSON и интерфейс предполагается публиковать на одном домене, без токенов в браузере. Избранное и прогресс хранятся в localStorage, отдельно от базы, без синхронизации устройств.

## Интеграции и ограничения
- Wolt: официальный список в Грузии и JobPosting на страницах вакансий.
- Welo Data: публичный Lever API. Приглашения в базу кандидатов (talent_pool) отделены от оплачиваемых вакансий.

Покрытие остальных источников описано ниже; проверка общей страницы не подтверждает отдельные проекты. Регистрация на платформе не подтверждает работу или выплаты. География не гарантирует соответствие языковым требованиям. Выплаты, KYC и ставки из Excel остаются неподтверждёнными.

Ошибка источника не обновляет last_verified_at и не закрывает запись. Закрытие требует минимум двух подтверждений отсутствия с интервалом 12 часов. Подтверждение в интерфейсе устаревает через 48 часов. История — check-history.json; исходные записи не удаляются.

## Автоматизация
.github/workflows/radar.yml содержит ручной запуск и расписание: 10:13, 11:43 и 14:43 Asia/Tbilisi (06:13, 07:43 и 10:43 UTC). Возможны задержки GitHub. scheduled_run_confirmed устанавливается только после события schedule; ручной тест не подтверждает плановый запуск.

Workflow тестирует правила, опрашивает источники, собирает снимок и сохраняет данные в git. Сайт не публикует. last_run_at — попытка запуска, last_database_update — сохранение базы, last_checked_at — попытка проверки записи, last_verified_at — подтверждение. Сохранение ошибок не подтверждает вакансии.

## Настройка
Изменять dist/data/search-config.json: ключевые слова, disabled_categories, исключённых работодателей и языки заголовков, форматы, занятость, приоритеты, geographic_terms. Расширение стран требует также изменения географических терминов и параметров источников: Wolt сейчас ограничен Грузией. Новый сайт обычно требует отдельного адаптера scripts/radar.py и записи sources.json. Исключённые платформы автоматически не возвращаются.

## Разработка
Python 3.12, мониторинг использует стандартную библиотеку.

```sh
python -m unittest discover -s tests -v
python scripts/radar.py
python scripts/build.py
```

scripts/import_data.py — только первоначальный импорт: повторный запуск перезапишет рабочие результаты. Не включать в ежедневный workflow.

Тесты покрывают ошибки, закрытие, повторное открытие, дедупликацию, географию, исключения, влияние конфигурации, даты, обнаружение новых записей и talent_pool. Синтетические находки не являются реальными вакансиями. dist/qa.html проверяет семь ширин; Chromium не заменяет реальное устройство Safari/iPhone.

## Публикация и обновления
GitHub Pages получает содержимое dist через .github/workflows/pages.yml. Публикация запускается после изменений main, вручную и после завершения Update job radar (включая сохранённые ошибки). Событие workflow_run необходимо: коммит от GITHUB_TOKEN сам по себе не запускает push-workflow.

Для изменения сайта редактируйте dist/index.html, dist/style.css и dist/app.js. Настройки поиска — dist/data/search-config.json. Можно попросить ассистента внести изменения; после коммита main сайт обновляется автоматически. Ручная проверка: Actions → Update job radar → Run workflow. Избранное и прогресс остаются локальными в браузере.

Основной запуск в 10:13 Тбилиси и повторные в 11:43 и 14:43 могут задерживаться. Публичные неактивные репозитории могут потребовать повторного включения расписания; следите за датой последнего обновления на Dashboard. Подтверждение планового запуска отображается отдельно от ручного теста. Платные API и подписки не используются.

## Расширение источников
Поиск и проверка конкретных объявлений: Wolt, Welo Data, Bolt, RWS TrainAI, SupportYourApp, TELUS Digital AI, Jobs.ge. Каждый источник проходит независимую проверку; недоступность не означает отсутствие вакансий.

Для uTest, DataForce, ModSquad, Mindrift, OneForma, CrowdGen, Outlier, Diaspire, Stafka и LinkedIn выполняется только проверка доступности публичной страницы по robots.txt. Это НЕ интеграция поиска проектов. Ошибка, ограничение robots, необходимость входа или изменение разметки сохраняются в журнале. Доступность страны, выплаты и ставки не подтверждаются по факту открывающейся страницы.

Изменения интеграций сначала проверяются в source-expansion: тесты и реальный опрос, без сохранения рабочей базы и без публикации. После проверки перенос в main запускает обновление базы; публикация получает результаты завершённого обновления.

Jobs.ge: сверка текущего списка с названием и работодателем в объявлении; до 40 релевантных страниц за запуск. Даты без года сохраняются исходным текстом, published_at не выдумывается. TELUS может блокировать GitHub runner; в этом случае результат — ошибка проверки. source-history.json хранит результаты источников, включая проверки публичных страниц.

## Надёжность проверок
Jobs.ge: обход всех объявленных страниц (предел 30), затем до 40 подходящих карточек, сначала все сохранённые ID. Ошибка любой страницы не считается закрытием вакансий. Сохранённые ID вне полного списка проверяются по прямой ссылке; 404/410 требует повторного подтверждения через 12 часов. Новые объявления проходят search-config.json. Поиск по всему LinkedIn не реализован: вместо заблокированных объявлений подключены официальные списки COLIBRIX ONE (Workable), Pharmbills (Georgia) и Concentrix (публичный jobsData). Привязки проверенных соответствий хранятся в source_aliases; исходные поля Excel сохранены. Временные 429/5xx и сетевые ошибки повторяются до трёх попыток; 403 и запреты robots не обходятся. Точный запуск в назначенную минуту не гарантируется GitHub.
